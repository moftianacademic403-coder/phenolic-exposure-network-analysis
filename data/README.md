# Input data

The analysis expects a workbook named `total.xlsx` with a worksheet named `total`.

Required fields:

- identifiers and group: `ID`, `group`;
- exposures: `BPA`, `Triclosane`, `Triclocarban`;
- covariates: `age`, `bminew`, `duration_job`, `sigar`, `hookah`;
- biological effect biomarkers: WBC, Neutrophils, Lymphocytes, Monocytes, Eosinophils, RBC, HB, HCT, MCV, MCH, MCHC, Platelets, RDW, Creatinine, bilirobin_total, biliroubin_direct, AST, ALT, ALK, Albumin, BUN, PT, PTT, T4, T3, TSH, IL6, TNF_alpha, OHdG8, CRP, and ESR.

Participant-level data are intentionally excluded from version control.
